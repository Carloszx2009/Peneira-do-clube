# Peneira do Clube

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar um site para divulgar uma peneira de futebol e permitir que novos jogadores tenham a oportunidade de participar da seleção do clube.

## Objetivo

Encontrar novos talentos para fazer parte da equipe de futebol do clube.

## Funcionalidades

- Página inicial de apresentação.
- Menu de navegação.
- Informações sobre a peneira.
- Área de contato.
- Formulário de inscrição dos jogadores.
- Mensagem de confirmação após o envio da inscrição.

## Tecnologias utilizadas

- HTML: estrutura do site.
- CSS: aparência e personalização da página.
- JavaScript: funcionalidades e interação com o usuário.

## Informações da peneira

- Data: 15/12/2026
- Horário: 09:00
- Local: Campo do Clube.

## Como acessar o projeto

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo index.html.
3. Execute a página no navegador.
